# 📝 Görev Yönetim Sistemi (Todo App)

ReactJS kullanılarak geliştirilmiş, kullanıcıların günlük görevlerini kolayca yönetmesini sağlayan basit ve modern bir görev yönetim uygulamasıdır.

## 🚀 Canlı Demo

[Uygulamayı Görüntüle](https://veyseltodo-app.netlify.app/)

## 📌 Proje Hakkında

Bu proje, JavaScript kütüphanelerinden ReactJS kullanılarak geliştirilmiştir. Kullanıcılar uygulama üzerinden görev ekleyebilir, mevcut görevlerini listeleyebilir, güncelleyebilir ve silebilir.

Görevlerin tarayıcıda saklanması için LocalStorage kullanılmıştır. Böylece sayfa yenilendiğinde kayıtlı görevler korunur.

## ✨ Özellikler

- ➕ Yeni görev ekleme
- 📋 Görevleri listeleme
- ✏️ Mevcut görevleri güncelleme
- 🗑️ Görev silme
- ✅ Görevleri tamamlandı olarak işaretleme
- 💾 LocalStorage ile verileri saklama
- 📊 Toplam ve tamamlanan görev sayısını görüntüleme

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Kullanım Amacı |
|---|---|
| ReactJS | Kullanıcı arayüzü geliştirme |
| JavaScript | Uygulama mantığı |
| Vite | Proje geliştirme ortamı |
| Tailwind CSS | Tasarım ve stil |
| LocalStorage | Verilerin tarayıcıda saklanması |
| GitHub | Kaynak kod yönetimi |
| Netlify | Uygulamanın yayınlanması |

## ⚙️ Kurulum

Projeyi bilgisayarınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz.

**1. Projeyi klonlayın**

```bash
git clone https://github.com/eoi101/todo-app.git
```

**2. Proje klasörüne girin**

```bash
cd todo-app
```

**3. Gerekli paketleri yükleyin**

```bash
npm install
```

**4. Projeyi çalıştırın**

```bash
npm run dev
```

Tarayıcı üzerinden aşağıdaki adrese giderek uygulamayı görüntüleyebilirsiniz:

```text
http://localhost:5173
```

## 🏗️ Build Alma

Projeyi production ortamı için derlemek amacıyla:

```bash
npm run build
```
